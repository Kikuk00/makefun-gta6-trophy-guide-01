Leonida Platinum — GTA VI Trophy Guide & Tracker. An offline web app that guides and tracks all 55 PlayStation 5 trophies of Grand Theft Auto VI: a checklist with the official names, descriptions and grades (1 platinum, 2 gold, 6 silver, 46 bronze), an own-words guide with cited sources for every trophy, a 5-stage roadmap to the platinum, missable-trophy flags, progress saved on your own machine, filters, and a spoiler setting for hidden trophies. No network requests; no Rockstar logo or artwork.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
